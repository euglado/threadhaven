# Contributing / Katkı

Describe the concrete problem and expected behavior, with sanitized steps. Never submit `.env`, bot tokens, personal IDs or private conversations. Use Node 24 and `npm ci --ignore-scripts`, then `npm run check` and `npm audit --audit-level=low`. Add meaningful regression coverage for behavior/security changes. CI also checks Node/Bash helper syntax on three OSes. Keep dependencies exact, retain least permissions and document Turkish/English user-facing changes. Mocked tests cannot replace an operator's live test in their own disposable server. Delete only your own test thread manually. Contributions are under MIT.

Somut sorunu, beklenen davranışı ve gizli veriden arındırılmış adımları anlatın. `.env`, token, kişisel kimlik veya özel konuşma göndermeyin. Node 24 ve `npm ci --ignore-scripts` ardından `npm run check` ve `npm audit --audit-level=low` çalıştırın. Davranış/güvenlik değişikliğine anlamlı regresyon testi ekleyin. CI üç işletim sisteminde Node/Bash yardımcı sözdizimini de kontrol eder. Bağımlılıkları tam sürüme sabitleyin, en az izinleri koruyun ve kullanıcıya dönük değişiklikleri iki dilde belgeleyin. Sahte etkileşim testleri kendi deneme sunucunuzdaki canlı doğrulamanın yerini tutmaz. Yalnızca kendi test başlığınızı elle silin. Katkılar MIT kapsamındadır.
