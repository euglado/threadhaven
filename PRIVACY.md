# Privacy / Gizlilik

ThreadHaven processes only slash-command titles, selected language, guild/role/channel metadata and individual organizer/bot memberships needed for authorization. It reads no message content and requests no privileged intents. Its public thread creation request goes to Discord only. There is no database, draft file, telemetry, bulk member download or third-party transfer.

Five-minute drafts hold title, parent name and user/guild/channel/private-message IDs in RAM; they expire on access and are pruned every 30 seconds. Used/cancelled drafts are removed immediately. Bounded cooldown IDs last 5/60 seconds plus cleanup delay. Active request locks persist until completion. Restart discards this application state. The Gateway library can retain guild/role/channel metadata in RAM; member/message caches are disabled. Individual REST results are transient. Bot token is stored in local `.env` or hosting environment, outside version control.

Created threads and Discord's own interaction/audit records can persist after the bot stops. Archiving is not deletion. Discord controls retention and native notifications. Device/host administrators may access memory and environment. The bot logs only generic startup/connection/configuration messages, not titles, IDs, tokens or raw errors. See README for setup, deletion and residual permission race behavior. Server owners should tell members about the bot and apply their own applicable data obligations.

ThreadHaven yalnızca komut başlığı, dil, sunucu/rol/kanal metaverisi ve izin için gereken organizatör/bot tekil üyelik verisini işler. Mesaj içeriği okumaz, ayrıcalıklı intent istemez. Oluşturma isteği yalnızca Discord'a gider. Veritabanı, taslak dosyası, telemetri, toplu üye indirme veya başka hizmete aktarım yoktur.

Beş dakikalık taslaklar başlık, ana kanal adı ve kullanıcı/sunucu/kanal/özel mesaj kimliklerini RAM'de tutar. Süresi dolanlar erişimde veya 30 saniyelik temizlikte silinir; kullanılan/iptal edilenler hemen kaldırılır. Sınırlı cooldown kimlikleri 5/60 saniye artı temizlik gecikmesi boyunca kalır. Etkin istek kilitleri işlem bitene kadar kalır. Yeniden başlatma bu uygulama durumunu siler. Gateway kitaplığı sunucu/rol/kanal metaverisini RAM'de tutabilir; üye/mesaj önbelleği kapalıdır. Tekil REST sonuçları geçicidir. Token Git dışındaki yerel `.env` veya hosting ortamında saklanır.

Oluşan başlıklar ve Discord'un etkileşim/denetim kayıtları bot kapansa da kalabilir. Arşivleme silme değildir. Saklama süresi ve yerleşik bildirimler Discord'a aittir. Cihaz/hosting yöneticileri bellek ve ortama erişebilir. Bot başlık, kimlik, token veya ham hata yerine yalnızca genel başlangıç/bağlantı/yapılandırma mesajları yazdırır. Kurulum, kaldırma ve izin yarışı sınırları README'dedir. Sunucu sahipleri üyeleri bilgilendirmeli ve kendilerine uygulanabilecek veri yükümlülüklerini değerlendirmelidir.
